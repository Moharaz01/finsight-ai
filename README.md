## 📌 What This Project Does

FinSight AI pulls live market data for 10 UK-relevant assets — FTSE 100, HSBC, BP, AstraZeneca, Unilever, Rolls-Royce, GBP/USD, Gold, Bitcoin, and Ethereum — and runs it through eight analysis modules, from deep-learning price forecasting to regulatory-style compliance disclosures. It's built as an educational and research tool, not a trading system: every forecast page carries explicit "not financial advice" disclaimers, in keeping with its own FCA-aware design principles (see below).

## 🧩 Modules

| Page | What It Does |
|------|--------------|
| 🏠 Market Overview | Live price, change, and key stats for the selected asset |
| 📈 Price Forecasting | LSTM / GRU / Bidirectional LSTM deep learning models forecast price direction over a 7–90 day horizon |
| 🔍 Anomaly Detection | DBSCAN (density-based clustering) flags statistically unusual price movements |
| 🎭 Market Regimes | K-Means clustering + PCA on rolling returns, volatility, and momentum to classify the current market regime |
| ⚠️ Risk Engine | Value at Risk (VaR) and Conditional VaR (CVaR) calculated from historical returns |
| 📊 Technical Analysis | Moving averages, Bollinger Bands, RSI, MACD, ATR, volatility and momentum, plotted interactively |
| 🧠 Deep Learning Lab | Documents the LSTM/GRU/BiLSTM architectures, training methodology, and model limitations |
| 🔒 FCA & GDPR | Explains the app's FCA AI-principles awareness, UK GDPR data-handling position, and full risk disclaimers |

## 🏗️ How It Actually Works

This is a **single-file Streamlit application** — there is no separate backend. Market data is fetched live from Yahoo Finance via `yfinance` (5-minute cache) on every asset/period selection; all model training and inference (LSTM/GRU/BiLSTM, K-Means, DBSCAN, PCA, VaR/CVaR) runs locally in the Streamlit session using scikit-learn and TensorFlow. No data is persisted beyond the browser session, no accounts are required, and nothing is sent to third parties beyond the Yahoo Finance API itself.

**On the FCA/GDPR framing:** FinSight AI is not FCA-regulated and does not claim to be. The "FCA & GDPR" page documents how the app's design *aligns with* FCA AI principles (transparency, human oversight, no automated recommendations) and UK GDPR Article 25 (privacy by design) — it's a compliance-aware design exercise, not a regulatory claim.

## 🛠️ Tech Stack

- **Deep Learning:** TensorFlow / Keras — LSTM, GRU, Bidirectional LSTM
- **Machine Learning:** scikit-learn — K-Means, DBSCAN, PCA
- **Data:** `yfinance` (Yahoo Finance API) — live market data, no API key required
- **Technical Indicators:** `ta`, custom pandas/numpy calculations
- **Visualisation:** Plotly — interactive financial charting
- **Framework:** Streamlit
- **Risk:** Custom VaR/CVaR engine (`scipy`, `statsmodels`)

## 🚀 Running Locally

```bash
git clone https://github.com/Moharaz01/finsight-ai.git
cd finsight-ai
pip install -r requirements.txt
streamlit run finsight_app.py
```

Opens at `http://localhost:8501`. No API keys or environment variables needed — the Yahoo Finance data used is free and public.
